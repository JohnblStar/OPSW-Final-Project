# 시니어 복약 관리 애플리케이션

본 프로젝트는 간병인이 여러 명의 어르신을 효율적으로 관리할 수 있도록 돕는 모바일 기반 복약 관리 애플리케이션이다.  
어르신별 복약 일정 관리, 복약 여부 기록, 알림 제공을 통해 복약 누락을 줄이고 보호자의 관리 부담을 완화하는 것을 목표로 한다.

## 프로젝트 개요

고령 인구 증가와 함께 복약 관리의 중요성이 커지고 있지만, 실제 현장에서는 복잡한 약 복용 일정과 기록 관리의 어려움으로 인해 복약 누락이나 지연이 빈번하게 발생하고 있다.  
본 프로젝트는 이러한 문제를 해결하기 위해 간병인을 중심으로 한 복약 관리 시스템을 설계하였다.

간병인은 하나의 계정으로 여러 명의 어르신을 등록하고 관리할 수 있으며,  
각 어르신의 복약 상태를 시간대별로 확인하고 기록할 수 있다.  
이를 통해 복약 현황을 한눈에 파악하고, 복약 지연이나 누락을 빠르게 인지할 수 있도록 한다.

---

## 주요 기능

- 회원가입 및 로그인 기능
- 간병인 계정 기반 어르신 다중 관리
- 어르신별 복약 스케줄 등록
- 아침, 점심, 저녁 복약 상태 기록
- 복약 완료, 미복용, 지각 상태 관리
- 캘린더 기반 복약 이력 확인
- 복약 지연 시 보호자 알림 전송 구조 설계
- 복약 패턴 기반 리포트 화면 제공

## OCR 및 AI 기반 약 정보 처리 구조

초기 설계에서는  
약 봉투 이미지를 OCR로 분석한 뒤 OpenAI 모델을 활용하여 약 설명과 복약 가이드를 생성하는 구조를 계획하였다.

그러나 실제 개발 과정에서 다음과 같은 문제가 발생하였다.

- OCR 결과의 정확도 편차로 인해 약 이름 인식 오류 발생
- OpenAI 단독 사용 시 근거 데이터 부족으로 인한 정보 신뢰성 문제
- 약국 또는 병원별 약 명칭 차이로 인한 조회 불가능 사례 발생

이러한 문제를 개선하기 위해  
현재 프로젝트에서는 OCR 결과를 기반으로 Gemini 모델을 활용하는 방향으로 파이프라인을 수정하였다.  
Gemini 모델은 상대적으로 긴 컨텍스트 처리와 정보 요약에 강점이 있어,  
OCR 결과 후처리 및 약 정보 설명 생성 단계에서의 안정성을 높이는 데 목적을 두고 있다.

해당 구조는 향후 식약처 의약품 Open API 등 공식 데이터와 연동하여  
AI 응답의 신뢰도를 강화하는 방향으로 확장 가능하도록 설계되었다.

## 프로젝트 구조 개요

- 프론트엔드는 Flutter 기반 단일 코드베이스로 Android 및 iOS를 지원한다.
- 인증 및 사용자 데이터는 Firebase Authentication과 Firestore를 사용한다.
- OCR 및 AI 처리는 백엔드 서버에서 담당한다.
- 프론트엔드는 API 연동 전 단계까지 더미 데이터 기반으로 UI와 로직을 구현하였다.
